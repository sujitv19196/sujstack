# Security

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this
repository. Do not open a public issue for it.

A vulnerability in a port or adapter belongs to the kit; report it on
[sujstack-kit](https://github.com/sujitv19196/sujstack-kit/security) instead.

Only the latest release is supported. A fix ships as a new release, with upgrade notes in
`CHANGELOG.md` if an app has to do anything beyond merging it.
